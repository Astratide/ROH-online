## 二、法术详述页格式

```html
<h4 id="吸收动能">吸收动能丨Absorb Kinetics</h4>
<p><i>一环 防护（岩土；奇械师，游侠）</i><br>
<b>出处：</b>《罗德岛外勤指南（Rhodes Operations Handbook）》<br>
<b>施法时间：</b>反应，在你受到穿刺、挥砍、钝击伤害时执行<br>
<b>施法距离：</b>60尺<br>
<b>法术成分：</b>S<br>
<b>持续时间：</b>1轮<br>
正文……<br>
<b>升环施法：</b>……</p>
```

### 硬性规则

1. 标题分隔符必须是 **`丨`（U+4E28）**，不是 `｜`（U+FF5C）——后者会导致英文名解析失败、首字母排序失效；
2. 元信息行必须是**单行**，以 `<p><i>` 开头、`</i><br>` 结尾（缺一不可，否则全文变斜体）；
3. 元信息内容格式：`环阶 学派（领域1，领域2；职业1，职业2）`
   - **环阶**：戏法 / 一环 / 二环 / 三环 / 四环 / 五环 / 六环 / 七环 / 八环 / 九环（10 选 1）
   - **学派**：防护 / 咒法 / 预言 / 惑控 / 塑能 / 幻术 / 死灵 / 变化（8 选 1）
   - **分号 `；` 之前 = 领域表**（可多个，用 `，` 分隔）
   - **分号 `；` 之后 = 原版职业**（可多个，用 `，` 分隔）
   - **不写项目职业**（术师/辅助/医疗/特种）——项目职业只出现在法表与速查职业标签里
   - **荒洲（EGW）法术**：分号后写 `时间魔法` / `重力魔法`（代替原版职业的位置）
   - 无领域归属时**不写分号**：`塑能 戏法（术士，法师）`
4. **领域顺序**：
   - 基础领域（固定顺序）：光芒 → 烈火 → 寒冰 → 流水 → 气尘 → 岩土 → 雷电 → 酸毒 → 黯蚀 → 空间 → 心魂 → 幻象 → 预知 → 自然 → 深海 → 炼金
   - 进阶领域（拼音序）：风暴雷鸣 → 光影心灵 → 辉煌烈焰 → 酷寒洪流 → 疗愈重塑 → 酸毒侵蚀 → 时空矢量
   - 基础领域在前、进阶领域在后
5. **职业顺序**（按英文首字母）：
   奇械师 Artificer → 吟游诗人 Bard → 牧师 Cleric → 德鲁伊 Druid → 圣武士 Paladin → 游侠 Ranger → 术士 Sorcerer → 魔契师 Warlock → 法师 Wizard
6. 字段顺序固定：出处 → 施法时间 → 施法距离 → 法术成分 → 持续时间 →（正文）→ 升环施法
7. 每个字段 `<b>字段名：</b>` 开头、`<br>` 结尾；条目最后以 `</p>` 结束
8. 条目内**不要空行**（`<h4>` 与 `<p><i>`、各字段之间紧挨着）

## 三、法术表构建格式

```html
<h6>岩土法术表Spells of Soil</h6>
<span class="grey">领域法术表（先决：…）</span><br>
<b>戏法：</b>塑土术<sup>XGE</sup>，魔石术<sup>XGE</sup>…<br>
<b>1环：</b>…<br>
<b>2环：</b>…<br>
```

- 表名行：`<h6>中文表名English Name</h6>`；表名去掉"法术表"即领域名（岩土法术表 → 岩土）；
- 环阶行标签必须是 **`<b>N环：</b>` 或 `<b>戏法：</b>`**（不能用 `<strong>`，解析会漏行）；
- 法术之间用 **`，`** 分隔；整行以 `<br>` 结尾；
- **非 PHB 法术必须带出处后缀** `<sup>缩写</sup>`（PHB 法术不加）：
  `血祭<sup>CM</sup>`、`元素风暴<sup>ROH</sup>`、`法术炮击<sup>AK5e</sup>`
- 出处缩写以**速查 `data-tags` 里的来源标签为准**（批量核对脚本见第五节）；
- 同一法术属于多张表时，每张表各出现一次。

常用缩写：PHB24 / XGE / TCE / FTD / KGE / ES / ROH / AK5e / CM / VSS / GMB / EGW / FR / SCC / UAH / HW / GGR / AI / AAG / SO / BMT / DM / ILL / BET / UA / SGEH / CAH / AI / AU / 模组

## 四、速查格式

```html
<tr data-spell="吸收动能Absorb Kinetics" data-tags="防护 一环 奇械师 游侠 言语 姿势 ROH 岩土">
  <td><A href="../第五章：施法规则/1环.html#吸收动能">吸收动能Absorb Kinetics</a></td>
  <td>一环</td><td>防护</td><td>奇 软</td>
  <td>V</td><td>S</td><td>×</td><td>×</td><td>×</td><td>ROH</td></tr>
```

### `data-tags` 顺序（八段）

1. 学派（8 选 1）
2. 环阶（`戏法(零环)` / `一环`…`九环`）
3. 职业（**全称**，按英文首字母序）
4. 成分（言语、姿势、材料）
5. 专注 / 仪式 / 价耗
6. 来源缩写（PHB24 / ROH / KGE / AU …，字母序）
7. 领域（基础领域固定序 → 进阶领域拼音序）
8. 杂项（时间魔法 / 重力魔法 / 重力 / 时间 / 模组 / 时序魔法 / 其他）
9. 项目职业（术师/辅助/医疗/特种）以职业标签形式出现在第 3 段

### 单元格（`<td>`，固定 10 列）

法术名 | 环阶 | 学派 | 职业 | 言语 | 姿势 | 材料 | 仪式 | 专注 | 来源

- **职业列用简写**：奇 诗 牧 德 帕 软 术 锁 法（空格分隔），但 `data-tags` 里必须全称；
- 来源列填缩写，**不允许留空**；
- 无职业的法术（如"思想编码"）职业列可空；
- 行尾允许大写 `</TR>`（历史遗留），新写请用小写 `</tr>`。

### 来源筛选框

```html
<b>来源：</b> <button onclick="select_all('book')">全选</button>
<input name="book" id="bk32" type="checkbox" checked="" value="CM"><label for="bk32">CM</label>
<input name="book" id="bk33" type="checkbox" checked="" value="AU"><label for="bk33">AU</label>
```

- 每个 `<input>` 后必须紧跟**自己的** `<label for="同id">`；
- 新增书时取 `bk` 最大号 + 1，不要插在别的 input 与 label 之间。

## 六、踩过的坑（务必避免）

1. **`｜` 与 `丨`**：标题里用错全角竖线 → 英文名解析失败、首字母排序失效。全库修正过 10 处。
2. **`</i>` 被吞**：用 `(<p><i>)(…)(</i>)` 三段捕获重建时，若返回值漏掉第三段 → 每改一次丢一次闭合标签 → **全文变斜体**。修复：重建时显式拼 `</i>`。
3. **`<br>` 被吞**：同上，重建元信息行时必须补回 `<br>`，否则环阶行会和下一行"出处"挤在一起。
4. **双括号**：`（炼金；仪式）（法师，奇械师）` —— 必须合并为一组，职业按规则排序。
5. **`<strong>`**：法表里用 `<strong>N环：</strong>` 会导致整行被漏解析（已全库改回 `<b>`）。
6. **领域解析丢名**：法表里 `名称<sup>缩写</sup>` 若按 `[^<]*` 截取会丢名字 → 解析时必须先 `re.sub(r"<[^>]+>", "", line)` 去标签。
7. **正则误吞前缀**：按"最后一个括号"匹配会把 `一环 防护` 前缀连同职业一起吞掉 → **按行定位、不要用跨段大正则**。
8. **速查来源列留空**：必须补上缩写（疾电剑/烈焰剑/凛霜剑 = VSS、崩坏现实/时光蹂躏 = EGW、血祭 = CM、弧光电荷 = GMB）。
